# まちめし 1.4.0

DeltaChat用の注文・調理・受渡し台帳です。現金、店舗用QR、外部の対応端末で行うバーコード決済の **手動会計記録** を追加しました。

## 同梱物

- `machimeshi-1.4.0.xdc`：DeltaChat用アプリ。拡張子は `.xdc` です。
- `machimeshi-1.4.0.html`：単一ファイルのブラウザー版。同じブラウザーの保存領域だけに記録し、別端末とは共有しません。
- [HTML操作マニュアル](machimeshi-1.4.0-manual.html)
- [Word操作マニュアル](machimeshi-1.4.0-manual.docx)
- [PDF操作マニュアル](machimeshi-1.4.0-manual.pdf)：画面模式図・比較表入り、全13ページ。
- `source-1.4.0/`：ソース・再生成スクリプト・自動テスト。

## 最初に行うこと

1. スタッフ用チャットにxdcを添付します。全員が **同じチャットの同じ1件のアプリ** を開いてください。
2. 起動時は顧客画面です。「スタッフ端末」を1回タップし、初期パスワード `1234` でスタッフ画面へ入ります。
3. 「設定・データ引継ぎ」で開催名・メニュー・価格を確認します。
4. 「支払方法と店舗用QR」で店舗で利用できる方法だけを有効にし、方法ごとに保存します。初期状態は現金とPayPayが有効です。PayPay加盟店として利用できない場合は無効にしてください。
5. QRを表示する場合は、加盟店向けに正式発行された店舗用の画像を登録します。未登録でも、店頭に掲示した正式なQRで案内できます。決済契約や店舗QRはこのアプリには付属しません。
6. 各端末で通知音を試聴し、試し注文で厨房への表示・呼出し音・会計記録の共有を確認します。試した注文は取消にします。実際に支払った試し注文の返金は、現金の返却または決済サービス側で別途行ってください。

## 支払いへの対応範囲

|方法|まちめしが行うこと|実際の支払い|
|---|---|---|
|現金|支払方法の選択、預かり金とお釣りの計算、受領確認の記録|受付でスタッフが現金を受け取ります|
|PayPay・au PAY・楽天ペイ・d払い|方法の選択、店舗QR画像と金額・案内の表示、スタッフによる確認記録|各社の正式な加盟店QRと公式決済アプリを使用します|
|バーコード|利用方法の案内、支払方法と結果の記録|契約済みのPOS・対応決済端末・公式アプリで読み取ります|

**まちめしから決済APIを呼び出して請求・自動入金確認・自動返金する機能はありません。** バーコードを読み取るだけで決済できる機能もありません。お客様の決済コード自体を入力・保存しないでください。加盟店契約と対応機器は店舗側で用意します。

## 注文と会計の流れ

1. 顧客は番号・商品・数量と支払方法を選び、「注文を登録する」を押します。
2. 顧客画面の「支払方法・QRの案内」で金額と案内を確認します。QRを開いただけでは支払済みになりません。同じスマートフォンで注文している場合は、受付の掲示QRをご利用ください。
3. スタッフは注文カードの「会計・支払確認」または一覧の「会計」を開きます。
4. 実際の支払方法と「支払済み」を選びます。現金の場合は預かり金を入力します。不足額のままでは支払済みにできません。
5. 現金の受領、または公式決済サービス側で店舗名・金額・決済結果を確認します。確認欄にチェックし、「会計記録を保存・共有」を押します。店舗側の決済番号と会計メモも任意で記録できます。

会計の確認担当者・日時・変更履歴が残ります。顧客画面から支払済みを記録する操作はできません。スタッフの画面切替は誤操作防止用で、共有履歴に対する暗号学的な認可機構ではありません。

無料注文は「支払不要」になります。全額の支払確認・全額の返金を記録する方式です。分割払い・一部返金・領収書の発行には対応していません。

## 取消と返金

- 状態の訂正は「詳細・状態を訂正」から行います。数量・商品・番号・メモの訂正は、元注文を取消にして正しい内容を新規登録します。
- 支払済みの注文を取消にすると、自動で **返金待ちという表示** になります。実際の返金処理は行いません。
- 現金の返却または決済サービス側で返金を実施してから、会計画面で「返金済み」を確認して記録します。元の支払方法と同じ方法で記録します。
- 支払記録のない注文を返金済みにすることや、返金待ちを未払いへ変更して消すことはできません。
- 支払済みを誤って記録した場合、取消前の注文なら「未払い」に訂正できます。実際に受領したお金を返す処理とは区別し、会計メモを残してください。

## 店舗用QRの登録

「設定・データ引継ぎ」→「支払方法と店舗用QR」で、対象サービスの画像を選び、プレビューを見て、その方法の「保存・共有」を押します。

PNG・JPEG・WebP、2MB以下の画像に対応します。最大640pxのPNGへ変換し、データURLが44,000文字以下の画像を共有します。上限を超えた場合は、店舗用QRを大きく鮮明に切り出した画像を使ってください。画像の縦横比は保ちます。QRの内容・支払先・読取り可能性は自動判定しないため、保存後に公式決済アプリで必ず確認してください。

現金・PayPay以外は初期状態で無効です。利用できるサービスだけを有効にします。支払方法の設定と画像は同じアプリ全体で共有されます。方法を無効にしても、過去の注文の支払方法・履歴は変わりません。

## 集計と保存

「集計・グラフ」の会計欄は、検索・日付の対象注文を集計します。

- **入金確認残高**：支払済みと返金待ちの合計です。返金済みは含みません。
- **未払い 注文分**：取消を除く未払い注文の金額です。
- **返金待ち・返金済み**：それぞれの状態の注文金額です。

これはスタッフの手動記録で、決済会社の振込明細や会計帳簿を自動取得したものではありません。

CSVには支払方法・支払状態・確認担当・確認日時・現金の預かり金・お釣り・店舗決済番号を追加しました。CSVは表示対象分の表計算用、JSONは全履歴の復元用です。注文内容はCSVで商品ごとの行になります。注文合計や支払記録の列を商品行ごとに重複加算しないでください。

## スタッフ切替と通知音

- タップ回数は1〜20、新しいパスワードは4〜128文字。変更には現在のパスワードが必要です。複数回タップの間隔は3秒以内です。
- 再起動すると顧客画面へ戻ります。スタッフは再認証してください。
- 新規注文音はスタッフ画面で鳴ります。受渡し音はスタッフと、その注文を登録した顧客端末で鳴ります。
- 顧客は同じ端末・同じアプリを開いて待ちます。スタッフ代理登録や顧客端末の情報がない注文はスタッフのみが対象です。
- 初期状態は音2種類ともオン・70％。スタッフ設定で個別のオン・オフと0〜100％の音量を保存し、試聴できます。
- 切替設定と通知音設定は **端末ごと** です。他の端末への遠隔設定やJSONへの書出しは行いません。
- 「音を有効にする」があれば押してください。閉じたアプリ・画面ロック・バックグラウンドでの音は保証しません。起動時の履歴・重複受信・JSON引継ぎ・見本データでは鳴りません。会計記録の更新だけでも注文音・受渡し音は鳴りません。

## 旧版からの移行

1. 旧アプリを削除する前に「JSONを書き出す」を実行し、DeltaChatの添付送信を確定して保存します。
2. 新しいxdcを同じスタッフ用チャットへ添付し、全員が新しい同じ1件を開きます。新しい添付へ履歴は自動移行しません。
3. 新版のスタッフ設定でJSONを読み込み、注文・開催情報・集計を確認します。
4. 旧版の会計情報のない注文は「未指定／未払い」と表示します。実際に支払済みだったかを確認して記録してください。勝手に現金払い済みとは判定しません。
5. 端末ごとの切替・通知音設定、呼出し先は別のアプリへ自動移行しません。必要な設定を再度行い、受付番号での案内も併用します。

1.4.0の会計・支払方法設定を含むJSONは1.4.0で読み込んでください。旧版では新しいイベントを扱えません。CSVからの復元には対応していません。

## 再生成とテスト

Windows PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\source-1.4.0\build.ps1
node .\source-1.4.0\test.cjs
node .\source-1.4.0\test-audio.cjs
node .\source-1.4.0\test-payments.cjs
```

xdcには `index.html`、`core.js`、`app.js`、`alerts.js`、`payments.js`、`icon.png`、`manifest.toml` を入れます。`webxdc.js` はDeltaChatが提供するためxdcに入れません。単一HTML版では必要なスクリプトを埋め込みます。

検証済み：注文・共有・認証・通知音の自動テスト、会計の金額・現金不足・取消返金・重複・競合・JSONのテスト、Chromeの独立環境での会計結果共有・画像取込・QR案内・CSV・モバイル表示。QR画像取込はテスト画像で検証しており、実際の支払いは行っていません。

実機DeltaChat、各社の決済・返金、実際の店舗QRの読取り、スピーカーからの発音は未確認です。運用前に各端末で確認してください。PDFは全ページの表示を確認し、Word版は内容・構造を検査しています。Word上の改ページ表示は未確認です。

参考：[PayPay公式の店舗向けガイド](https://image.paypay.ne.jp/pdf/startguide.pdf)、[au PAY公式の店舗向け案内](https://media.aupay.wallet.auone.jp/articles/10)、[webxdcの外部通信制限](https://webxdc.org/docs/spec/messenger.html)。
